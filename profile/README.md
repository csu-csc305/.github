# CSC 305 — Individual Software Design and Development

Course repositories for **CSC 305: Individual Software Design and Development** at
California Polytechnic State University, San Luis Obispo.

This organization contains software projects, programming assignments, and
supporting materials from multiple offerings of the course.

## Repository Organization

Repositories are organized by academic term and project:

`YYYY-Term-Project`

For example:

- `2026-Spring-ProjectOne`
- `2026-Spring-ProjectTwo`
- `2026-Spring-FinalProject`

When multiple repositories are associated with the same project, additional
descriptive identifiers may be included in the repository name.

## About the Course

CSC 305 focuses on the design and development of software at the individual
developer level, emphasizing software design principles, implementation,
refactoring, testing, and the creation of maintainable software systems.
